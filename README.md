# Debug Buddy

An IB Computer Science (2027 syllabus) trace-table game, from Mr. O's Arcade.

**Play:** https://ostromaj.github.io/robot_repair/

## How it works

- **Squash** – Bugs crawl across the Bolt OS desktop toward Bolt the robot. Click them to collect bytes.
- **Upgrade** – Spend bytes on an Auto-Zapper, Chain Lightning, Big Swatter, Firewall, Byte Doubler, Byte Miner and an EMP Blast.
- **Repair** – Each round The Glitch breaks one of Bolt's parts. Fix it by filling in a real trace table for a Python snippet, plus the printed output.
- **SL / HL** – SL covers loops, conditionals, strings, lists and 2D lists. HL adds recursion.

Snippets are randomly generated, and every table cell and output was checked against real Python. Single self-contained `index.html`, no build step. No flashing effects.
